# Task: Animated Rectangle Color and Transformation

This project draws a rectangle using OpenGL that gradually changes its color from red to white while performing magnification, squeezing, and translation in the X and Y directions over time.

Requirements:

- Rectangle displayed on the screen
- Gradual color transition from red to white and vice versa
- Magnification and shrinking over time
- Squeezing and stretching the rectangle
- Translation in the X and Y directions
- Continuous animation based on time
